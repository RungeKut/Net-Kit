# /export вместо серии print

## Что происходит

Осмотр по разделам (`/interface print`, `/ip address print`,
`/ip firewall filter print`, …) показывает **только то, что ты решил
спросить**. Раздел, о существовании которого не думаешь, остаётся невидимым,
и выводы получаются уверенно неверными.

## Почему это дорого

Реальный случай. На роутере искали, почему он не отвечает на ping со своего
же адреса. Осмотрены интерфейсы, адреса, маршруты, NAT, фаервол, DHCP,
Wi-Fi — картина не сходилась: счётчик правила `accept ICMP` ловил пакеты,
то есть роутер их **принимал**, но ответа не было.

Разгадка нашлась в выгрузке:

```
/routing rule
add action=unreachable dst-address=192.0.2.0/24 src-address=198.51.100.0/24
```

Ответ роутера уходил с адреса, попадавшего под это правило. В
`/ip firewall ...` такого не видно **никогда** — это другая подсистема.

В той же выгрузке нашлось ещё три вещи, которых не было ни в одном
`print`, что смотрели: `arp=reply-only` на мосту, шейпер на гостевую сеть
и `/interface wireless access-list` с временными окнами для устройств.

## Как правильно

```
/export file=osmotr
```

Забрать к себе и прочитать целиком:

```sh
scp user@192.0.2.1:osmotr.rsc .
```

Затем удалить с роутера — на младших платах свободно меньше мегабайта:

```
/file remove [find name="osmotr.rsc"]
```

Выгрузка читается за пару минут и содержит **всё**, включая разделы,
которые не пришли бы в голову.

## Как неправильно

Начинать с `/ip firewall filter print` и делать вывод «правил нет, значит
не блокируется». Блокировать может `/routing rule`, `/ip firewall raw`,
`/interface bridge filter`, `arp=reply-only`, `allowed-address` WireGuard
или список доступа Wi-Fi.

## Что важно знать про сам /export

Пароли, пресharedключи и приватные ключи в выгрузку **не попадают** —
RouterOS 7 их опускает. Публичные ключи, имена VPN-аккаунтов, адреса
и пробросы портов — попадают, поэтому файл хранится в `local/`
([40-03](../40_СРЕДА/40-03_локальные_данные_площадок.md)).

## Чем подтверждено

`grep "pre-shared-key\|password\|private-key" *.rsc` по двум выгрузкам —
ни одного совпадения со значением.
