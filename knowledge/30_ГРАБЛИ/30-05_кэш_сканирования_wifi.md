# Кэш сканирования Wi-Fi в Windows

## Что происходит

```
netsh wlan show networks
```

показывает список из кэша, а не свежий скан. Отсюда два симптома:

* сеть **в эфире**, но её нет в выводе;
* `netsh wlan connect` падает: «Указанная профилем сеть недоступна для
  подключения», хотя сеть работает.

Особенно надёжно воспроизводится сразу после отключения от другой сети.

## Как правильно

Повторять с паузами, пока не появится:

```sh
for a in 1 2 3 4 5; do
  netsh wlan connect name="SSID-A" interface="Wi-Fi" >/dev/null 2>&1
  sleep 3
  # проверить, появился ли адрес нужной сети
done
```

Пересканирование занимает несколько секунд. Обычно хватает второй-третьей
попытки. Готовая функция с повтором — `netkit/wifi.py`, `connect()`.

## Как неправильно

Сделать вывод «SSID не вещает» по одному пустому скану. В связке с
[30-04](30-04_running_false_у_виртуальной_точки.md) это приводит к
уверенному неверному диагнозу «точка доступа не поднялась».

## Чем подтверждено

Четыре попытки подключения подряд к только что покинутой сети — все
«сеть недоступна». Между ними `show networks` её не показывал. После
паузы сеть появилась в списке, подключение прошло с первой попытки.
