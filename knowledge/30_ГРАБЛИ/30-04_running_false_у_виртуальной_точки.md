# running=false — не поломка

## Что происходит

```
/interface print
 6     S wlan1                    ← нет флага R
```

Напрашивается вывод «радио не работает». Он неверен.

У беспроводного интерфейса RouterOS флаг `R` (running) означает **наличие
ассоциированного клиента**. Пустая точка честно показывает `false` и при
этом вещает.

## Как проверить по-настоящему

```
/interface wireless print              → disabled=no
/interface wireless registration-table print   → кто подключён
```

`disabled=no` и есть ответ на вопрос «включена ли точка».

Со стороны клиента — сканирование эфира, но с оговоркой
[30-05](30-05_кэш_сканирования_wifi.md): список сетей в Windows устаревший
и сам по себе ничего не доказывает.

## Как неправильно

Сделать вывод «SSID не в эфире» по паре `running=false` + пустой результат
`netsh wlan show networks`. Оба признака ложные, а вместе выглядят
убедительно.

## Чем подтверждено

Виртуальная точка с `disabled=false, running=false` и пустой таблицей
регистрации; после подключения клиента флаг `R` появился, SSID всё это
время был в эфире и виден с расстояния при повторном сканировании.
