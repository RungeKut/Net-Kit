# Локальные данные площадок

## Зачем разделение

У набора два разных содержимого, и смешивать их нельзя.

| Что | Где | Почему |
|---|---|---|
| Переносимое знание: как работает RouterOS, где грабли, как проверять | `knowledge/` | полезно на любой сети, публиковать безопасно |
| Карта конкретной сети: адреса, SSID, логины, кто где живёт | `local/` | бесполезно другим, опасно публиковать |

Признак, по которому отличить: **запись, из которой нельзя убрать
конкретные адреса, не сломав смысл, — не знание, а данные площадки.**

## Что кладётся в local/

* по файлу на площадку: `local/<имя>.md` — карта сетей, интерфейсы,
  списки, DHCP, туннели, кто пользуется;
* выгрузки конфигов `*.rsc` — они содержат адреса, пробросы и публичные
  ключи (пароли RouterOS 7 в выгрузку не пишет);
* пометки о незакрытых задачах на этой площадке.

Шаблон — `local/ПЛОЩАДКА-образец.md`.

## Что НЕ кладётся даже в local/

**Пароли.** Ни в файлах карт, ни рядом. Файл с паролем для скриптов
(`pw.txt`) создаётся на время работы и удаляется после. Он в `.gitignore`
по маске, но `.gitignore` — не защита, а страховка от случайности.

Правильнее — SSH-ключи:

```
/user ssh-keys import public-key-file=id_rsa.pub user=<логин>
```

После этого файл с паролем не нужен вовсе.

## Как писать карту площадки

Карта нужна, чтобы через полгода не собирать сведения заново. Минимум:

* сегменты: сеть, адрес роутера, интерфейс, кто там живёт;
* списки интерфейсов `LAN`/`WAN` — на них написаны почти все правила;
* чем и куда ходит наружу;
* **два пути управления** и какой из них независимый
  ([20-01](../20_ПРИЁМЫ/20-01_два_пути_до_роутера.md));
* кто ещё пользуется этой сетью — от этого зависит, можно ли менять
  правила ([30-10](../30_ГРАБЛИ/30-10_запрет_правки_общего_роутера.md));
* что намеренно устроено необычно — чтобы следующий не «починил» это;
* незакрытое, с готовыми командами.

## Правило обновления карты

**Изменил сеть — в тот же заход обнови карту площадки.** Устаревшая
карта хуже её отсутствия: по ней принимают решения.

Если при этом обнаружилось переносимое знание — оно идёт в `knowledge/`,
обезличенным, и в `CHANGELOG.md`. Одно изменение, две записи в разных
местах: данные в `local/`, знание в `knowledge/`.

## Проверка

```sh
git status --porcelain local/
```

Пусто (кроме `README.md` и образца) — значит, ничего не утекло.

## Чем подтверждено

`.gitignore` содержит `local/*` с исключениями для двух файлов;
`check_docs.py` отдельно проверяет, что в индексе git нет других файлов
из `local/`.
