# Проверка из нужной сети

## Задача

Проверка, идущая не тем путём, ничего не доказывает
([30-02](../30_ГРАБЛИ/30-02_свой_запрос_идёт_другим_путём.md)). Значит, надо
уметь отправить трафик именно через выбранный интерфейс.

Сложность: на машине с двумя интерфейсами трафик уходит туда, где
**метрика меньше**, а прав администратора для смены метрик может не быть.

## Решение: привязка к адресу источника

Windows использует strong host model: сокет, привязанный к адресу
интерфейса, отправляет **только через этот интерфейс**. Прав
администратора не требуется.

Узнать, что есть и куда пойдёт:

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where {$_.IPAddress -notlike '169.254*'} |
  Select IPAddress,InterfaceAlias,InterfaceIndex
Get-NetRoute -DestinationPrefix '0.0.0.0/0' | Select InterfaceAlias,InterfaceMetric
Find-NetRoute -RemoteIPAddress 8.8.8.8 | Select -First 1 IPAddress,InterfaceAlias
```

### ICMP

```
ping -S 192.0.2.10 -n 4 8.8.8.8
```

### HTTP

```
curl --noproxy '*' --interface 192.0.2.10 -o /dev/null -w "%{http_code}\n" http://example.com
```

`--noproxy '*'` обязателен — [30-06](../30_ГРАБЛИ/30-06_curl_уходит_в_прокси.md).

### TCP и DNS

Готовые функции — `netkit/probe.py`: `tcp()` привязывает локальный
`IPEndPoint` у `TcpClient`, `dns()` — у `UdpClient`.

## Важное ограничение

Привязка работает, **пока цель достижима через этот интерфейс**. Если у
машины есть подключённая сеть, покрывающая адрес назначения, пакет уйдёт
туда независимо от твоих намерений — так пересечение подсетей увело
проверки совсем не туда
([30-10](../30_ГРАБЛИ/30-10_пересечение_подсетей_между_площадками.md)).

Поэтому результат привязки надо **подтверждать со стороны роутера**:
счётчиками или conntrack. Не подтвердил — не измерил.

## Безопасный порядок переключения между сетями

1. Убедиться, что управление роутером идёт **не по тому интерфейсу**,
   который будешь переключать.
2. Проверить, что SSH по этому пути работает — **до** переключения.
3. Переключать.
4. Проверять.
5. Возвращать.

## Чем подтверждено

`ping -S <адрес Wi-Fi> 8.8.8.8` при проводе с меньшей метрикой: счётчик
forward на роутере Wi-Fi вырос на 7 пакетов. То есть привязка
пересилила выбор маршрута по метрике.
