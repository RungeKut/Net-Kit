# Порядок поиска неисправности

## Шаг 0. Разделить задачу надвое

Первый вопрос всегда один: **у самого роутера связь есть?**

```
/ping 8.8.8.8 count=4
:put [:resolve example.com]
```

* Роутер не пингует наружу → проблема в аплинке. Фаервол не трогать.
* Роутер пингует, клиенты нет → проблема между клиентом и роутером.

Это делит задачу пополам и экономит основное время.

## Шаг 1. «Нет интернета» — не диагноз

Разложить на три независимых вопроса:

| Проверка у клиента | Что означает провал |
|---|---|
| получил ли адрес | DHCP |
| `ping 8.8.8.8` по IP | маршрутизация, NAT, цепочка forward |
| `nslookup example.com` по имени | DNS |

**Пинг по IP идёт, сайты не открываются — это почти всегда DNS.**

## Шаг 2. Снять конфиг целиком

`/export`, а не серия `print` — [10-02](../10_API/10-02_export_вместо_print.md).

## Шаг 3. Читать фаервол по цепочкам

Вывод `print` перемешивает цепочки; смотреть раздельно:

```
/ip firewall filter print where chain=input
/ip firewall filter print where chain=forward
```

Порядок сверху вниз, первое совпадение выигрывает.
**Несовпавший пакет разрешается** — в RouterOS нет настраиваемой политики
цепочки. Поэтому отсутствие `drop` в конце — норма, а добавленное кем-то
`drop all else` резко меняет смысл всей цепочки.

## Шаг 4. Измерить счётчиками

[10-03](../10_API/10-03_счётчики_правил.md). Обнулить, воспроизвести,
посмотреть.

## Шаг 5. Рассуждение о порядке правил

Самый дешёвый способ получить вывод — понять, **что вообще может дойти**
до подозрительного правила.

Пример. В цепочке `input`:

```
поз. 9   drop  in-interface-list=!LAN     ← отсекает всё, что не из LAN
поз. 16  drop  udp dst-port=53            ← комментарий «DNS из интернета»
```

Правило 9 стоит раньше и отбрасывает всё, что не из LAN. Значит до
правила 16 физически доходит **только трафик из LAN**. Следовательно
правило, названное «блокировать DNS снаружи», режет DNS **только своим**,
а заявленной защиты не даёт вовсе — её уже обеспечило правило 9.

Вывод общий: **читать не комментарий, а условия и позицию**. Комментарий
отражает намерение автора, а не поведение.

## Чем подтверждено

Рассуждение подтверждено счётчиками: у правила 9 — 2 пакета, у правила
16 — 1722. Всё сходится: до него доходит много, и всё это локальное.
